# ERM «Фасады Сысолы» — Этапы разработки v1.0

---

# 🧭 Общая стратегия разработки

Система строится по принципу:

> сначала поток производства → потом экономика → потом операции → потом аналитика → потом удобство

---

# 🟢 ЭТАП 0 — База (Foundation)

## 🎯 Цель
Поднять технический каркас системы.

## Backend
- Node.js + TypeScript + Fastify
- подключение MySQL (Beget)
- Prisma ORM + миграции
- базовая структура модулей
- авторизация (JWT или session) и **роли с первого дня**: администратор, работник (цех), заказчик — модель прав и проверки на уровне API

## Frontend
- React + Vite + TypeScript
- базовый layout
- роутинг (React Router)
- API client слой
- разделение сценариев по роли (в т.ч. **кабинет заказчика**: только свои заказы, read-only)

## CI/CD
- GitHub Actions
    - build frontend
    - deploy на Beget (FTP)

## 📦 Результат
- система запускается end-to-end
- пустой UI + API работает
- вход и ограничения по ролям заданы сразу (без откладывания RBAC на поздние этапы)

---

# 🟡 ЭТАП 1 — Ядро системы (Orders + Stages)

## 🎯 Цель
Сформировать производственный поток.

## Backend
- CRUD заказов
- CRUD этапов (динамические)
- перемещение заказа между этапами
- **audit log в полном объёме по BR** (п. 11): пользователь, время, тип изменения, diff; на этом этапе — смена этапа и изменения полей заказа; события по фасадам и цене подключаются в этапе 2

## Frontend
- список заказов
- создание заказа
- карточка заказа (минимальная)
- канбан доска этапов
- заказчик: список и просмотр **только своих** заказов
- просмотр истории изменений (audit) там, где уместно по роли

## 📦 Результат
- заказ движется по цеху вручную

# 🟠 ЭТАП 2 — Фасады и стоимость

## 🎯 Цель
Добавить экономическую модель.

## Backend

## 📦 Результат

# 🟣 ЭТАП 4 — Раскрой (stateless модуль)

## 🎯 Цель
Производственная функция раскроя.

## Backend
- cutting service (stateless)
- группировка фасадов:
    - material (MDF)
    - thickness
- генерация раскроя по группам
- **без сохранения** результата раскроя и PDF на сервере: только расчёт и отдача данных/потока для PDF клиенту

## Frontend
- кнопка “Раскрой”
- результат в новой вкладке
- PDF: сформировать и скачать у пользователя; **не** складывать в `/uploads` и не привязывать к заказу как файл

## 📦 Результат
- система показывает раскрой и даёт сгенерировать PDF без хранения у себя
